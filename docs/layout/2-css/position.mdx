# 2.12 Позиционирование элементов (position)

В этом уроке я расскажу тебе про одну из самых важных тем в CSS — позиционирование! С помощью свойства `position` ты сможешь размещать элементы именно там, где нужно: создавать модальные окна, фиксированные меню, всплывающие подсказки и многое другое.

## Что такое позиционирование

Позиционирование — это способ управлять тем, где именно на странице будет находиться элемент. По умолчанию все элементы идут друг за другом в потоке документа, но с помощью `position` можно "вытащить" элемент из этого потока и разместить в любом месте.

## Типы позиционирования

### 1. static (по умолчанию)

```css
.element {
  position: static; /* это значение по умолчанию */
}
```

Элемент остается в обычном потоке документа. Свойства `top`, `right`, `bottom`, `left` не работают.

### 2. relative (относительное)

```css
.element {
  position: relative;
  top: 20px;
  left: 30px;
}
```

Элемент остается в потоке документа, но **сдвигается относительно своего обычного места**. Очень полезно для небольших корректировок положения!

:::tip[Важно!]
При `position: relative` элемент сдвигается, но **место, которое он занимал, остается зарезервированным**. Другие элементы не "подтягиваются" на его место.
:::

### 3. absolute (абсолютное)

```css
.element {
  position: absolute;
  top: 50px;
  right: 20px;
}
```

Элемент **полностью выходит из потока документа** и позиционируется относительно ближайшего родителя с `position` отличным от `static`. Если такого родителя нет — относительно всей страницы.

### 4. fixed (фиксированное)

```css
.element {
  position: fixed;
  top: 0;
  left: 0;
}
```

Элемент фиксируется относительно **окна браузера** и не двигается при прокрутке страницы. Идеально для шапок сайта, плавающих кнопок "Наверх" и уведомлений!

### 5. sticky (липкое)

```css
.element {
  position: sticky;
  top: 10px;
}
```

Элемент ведет себя как `relative`, пока не достигнет указанной позиции при прокрутке, после чего "прилипает" как `fixed`. Отлично для навигации, которая должна остаться видимой при скролле!

## Свойства для позиционирования

Когда ты задаешь `position` (кроме `static`), становятся доступны свойства:

- `top` — расстояние от верхнего края
- `right` — расстояние от правого края  
- `bottom` — расстояние от нижнего края
- `left` — расстояние от левого края

```css
.popup {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-left: -150px; /* половина ширины */
  margin-top: -50px; /* половина высоты */
}
```

## z-index: управление слоями

Когда элементы накладываются друг на друга, важно контролировать, какой будет сверху:

```css
.modal {
  position: fixed;
  z-index: 1000; /* большое значение = элемент сверху */
}

.header {
  position: fixed;
  z-index: 100;
}
```

Чем больше значение `z-index`, тем выше элемент в "стопке".

## Практические примеры

### Пример 1: Фиксированная шапка

```html
<header class="fixed-header">Я всегда наверху!</header>
<main class="content">
  <p>Много текста...</p>
  <!-- Много контента для прокрутки -->
</main>
```

```css
.fixed-header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  background: #2196f3;
  color: white;
  padding: 16px;
  z-index: 100;
}

.content {
  margin-top: 60px; /* отступ, чтобы контент не прятался под шапкой */
  padding: 20px;
}
```

### Пример 2: Модальное окно

```html
<div class="modal-overlay">
  <div class="modal">
    <h2>Модальное окно</h2>
    <p>Важная информация!</p>
    <button>Закрыть</button>
  </div>
</div>
```

```css
.modal-overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0, 0, 0, 0.5); /* полупрозрачный фон */
  z-index: 1000;
}

.modal {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-left: -200px; /* половина max-width */
  margin-top: -100px; /* примерная половина высоты */
  background: white;
  padding: 32px;
  border-radius: 12px;
}
```

### Пример 3: Всплывающая подсказка

```html
<div class="tooltip-container">
  Наведи на меня
  <div class="tooltip">Это подсказка!</div>
</div>
```

```css
.tooltip-container {
  position: relative;
  display: inline-block;
  padding: 8px 16px;
  background: #e3f2fd;
  border-radius: 6px;
}

.tooltip {
  position: absolute;
  bottom: 100%;
  left: 50%;
  margin-left: -50px; /* примерная половина ширины */
  background: #333;
  color: white;
  padding: 8px 12px;
  border-radius: 6px;
  font-size: 0.9em;
  visibility: hidden; /* скрываем элемент */
}

.tooltip-container:hover .tooltip {
  visibility: visible; /* показываем элемент при наведении */
}
```

## Практическое задание

Создай страницу с разными видами позиционирования:

1. Создай файл `position.html`:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Позиционирование</title>
  <link rel="stylesheet" href="position.css">
</head>
<body>
  <header class="header">Фиксированная шапка</header>
  
  <main class="content">
    <h1>Главная страница</h1>
    
    <div class="relative-example">
      Относительное позиционирование
      <div class="relative-child">Я сдвинут!</div>
    </div>
    
    <div class="absolute-container">
      <div class="absolute-child">Абсолютно позиционированный</div>
    </div>
    
    <p>Много текста для прокрутки... Lorem ipsum dolor sit amet...</p>
    <!-- Добавь ещё много параграфов для проверки прокрутки -->
  </main>
  
  <button class="floating-btn">↑</button>
  
  <div class="modal-overlay" style="display: none;">
    <div class="modal">
      <h2>Модальное окно</h2>
      <p>Это пример модального окна!</p>
    </div>
  </div>
</body>
</html>
```

2. Создай файл `position.css` и добавь стили для всех примеров позиционирования.

## Итоги

Теперь ты умеешь:
- Использовать все типы позиционирования: static, relative, absolute, fixed, sticky
- Создавать фиксированные шапки и плавающие кнопки
- Делать модальные окна и всплывающие подсказки
- Управлять слоями с помощью z-index
- Правильно сочетать позиционирование с другими CSS-свойствами

Позиционирование — это мощный инструмент, который откроет тебе много возможностей для создания интерактивных и красивых интерфейсов!
