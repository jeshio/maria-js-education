# 1.2 Установка Node.js и создание первого React приложения 🛠️

Помнишь, как в прошлом уроке мы говорили о том, что дальше нужно установить Node.js и создать первое приложение? Настало время! Сегодня ты превратишь свой Mac в настоящую машину для разработки React приложений.

## Что такое Node.js? 🤔

:::tip[Node.js - твой новый друг]
**Node.js** — это программа, которая позволяет запускать JavaScript не только в браузере, но и на твоём компьютере. Вместе с Node.js устанавливается **npm** (Node Package Manager) — менеджер пакетов, который поможет устанавливать React и тысячи других готовых инструментов.
:::

Простыми словами: Node.js — это как переводчик, который понимает JavaScript и может выполнять его прямо на твоём Mac. А npm — это магазин приложений для программистов! Правда, они все бесплатные :)

## Установка Node.js 📥

### Способ 1: Через официальный сайт (рекомендуется)

1. **Перейди на сайт** [nodejs.org](https://nodejs.org/)
2. **Скачай LTS версию** (она самая стабильная)
3. **Запусти установщик** и следуй инструкциям
4. **Всё!** Node.js и npm установлены

### Проверим установку

Открой терминал и выполни команды:

```bash
# Проверяем версию Node.js
node --version

# Проверяем версию npm
npm --version
```

Если увидишь что-то вроде `v18.17.0` и `9.6.7` — всё отлично! Числа могут отличаться, это нормально.

:::warning[Если команды не работают]
Перезагрузи терминал или весь Mac. Иногда нужно время, чтобы система "увидела" новые программы.
:::

## Создание первого React приложения 🚀

Теперь самое интересное! Создадим твоё первое React приложение.

### Выбираем место для проектов

Сначала определись, где будешь хранить свои проекты:

```bash
# Переходим в домашнюю папку
cd ~

# Создаём папку для всех твоих проектов
mkdir dev-projects

# Переходим в неё
cd dev-projects
```

### Создаём React приложение

Сейчас мы будем использовать **Vite** — современный и быстрый инструмент для создания React проектов. Он намного быстрее старых инструментов!

Выполни эту команду:

```bash
npm create vite@latest my-first-react-app -- --template react
```

:::tip[Что происходит?]
- `npm create vite@latest` — создаёт новый проект с помощью Vite (самая современная версия)
- `my-first-react-app` — название твоего проекта
- `-- --template react` — говорим Vite, что хотим проект именно с React
:::

Эта команда работает намного быстрее — всего 30-60 секунд вместо долгих минут!

### Устанавливаем зависимости и запускаем

После создания проекта нужно установить зависимости и запустить:

```bash
# Переходим в папку с проектом
cd my-first-react-app

# Устанавливаем зависимости
npm install

# Запускаем сервер разработки
npm run dev
```

🎉 **Вуаля!** Должен открыться браузер с адресом `http://localhost:5173`, и ты увидишь крутящийся логотип Vite с React!

:::success[Поздравляю!]
Ты только что создала и запустила своё первое React приложение! Это серьёзное достижение! 🎊
:::

:::danger[Важно!]
Папку `node_modules` **никогда не трогай руками**! Она управляется автоматически через npm. Там тысячи файлов, и они нужны для работы React.
:::

## Твой первый React компонент 🧩

Открой VS Code и открой папку `my-first-react-app`. Найди файл `src/App.jsx`:

```jsx
import { useState } from 'react'
import reactLogo from './assets/react.svg'
import viteLogo from '/vite.svg'
import './App.css'

function App() {
  const [count, setCount] = useState(0)

  return (
    <>
      <div>
        <a href="https://vitejs.dev" target="_blank">
          <img src={viteLogo} className="logo" alt="Vite logo" />
        </a>
        <a href="https://react.dev" target="_blank">
          <img src={reactLogo} className="logo react" alt="React logo" />
        </a>
      </div>
      <h1>Vite + React</h1>
      <div className="card">
        <button onClick={() => setCount((count) => count + 1)}>
          count is {count}
        </button>
        <p>
          Edit <code>src/App.jsx</code> and save to test HMR
        </p>
      </div>
      <p className="read-the-docs">
        Click on the Vite and React logos to learn more
      </p>
    </>
  );
}

export default App;
```

### Давай изменим что-то!

Замени текст в `<p>` на что-то своё:

```jsx
<p>
  Привет, я изучаю React с Vite! 🚀
</p>
```

Сохрани файл (`Cmd + S`) и посмотри в браузер — изменения появятся мгновенно!

:::tip[Кнопка-счётчик]
Кстати, обрати внимание на кнопку `count is 0` — это уже рабочий React компонент с состоянием! Попробуй нажать на неё несколько раз. Это именно то, что мы будем изучать в следующих уроках! 🎯
:::

:::tip[Магия Vite]
Это называется "горячая перезагрузка" или HMR (Hot Module Replacement) — ты меняешь код, сохраняешь, и изменения сразу видны в браузере без перезагрузки страницы! Vite делает это супер быстро!
:::

## Основы JSX 📝

То, что ты видишь в `App.js` — это **JSX** (JavaScript XML). Это смесь JavaScript и HTML.

### Основные правила JSX:

1. **Используй `className` вместо `class`**:
   
   В HTML мы пишем `class="my-class"`, но в JSX нужно писать `className`. Это потому, что `class` — зарезервированное слово в JavaScript.
   
   ```jsx
   // Правильно
   <div className="my-class">Содержимое</div>
   
   // Неправильно в React
   <div class="my-class">Содержимое</div>
   ```

2. **Закрывай все теги**:
   
   В HTML некоторые теги можно не закрывать (как `<img>` или `<br>`), но в JSX **все теги должны быть закрыты**. Если тег не имеет содержимого, используй самозакрывающуюся форму с `/` в конце.
   
   ```jsx
   // Правильно
   <img src="photo.jpg" alt="Фото" />
   <br />
   
   // Неправильно в JSX
   <img src="photo.jpg" alt="Фото">
   <br>
   ```

3. **Один корневой элемент или Fragment**:
   
   Компонент может возвращать только **один** корневой элемент. Если нужно вернуть несколько элементов, оберни их в `<div>` или используй **React Fragment** `<>...</>` (это не создаёт лишний div в HTML).
   
   ```jsx
   // Правильно - обернуть в div
   function MyComponent() {
     return (
       <div>
         <h1>Заголовок</h1>
         <p>Текст</p>
       </div>
     );
   }
   
   // Правильно - использовать React Fragment (<>)
   function MyComponent() {
     return (
       <>
         <h1>Заголовок</h1>
         <p>Текст</p>
       </>
     );
   }
   
   // Неправильно - два элемента без обёртки
   function MyComponent() {
     return (
       <h1>Заголовок</h1>
       <p>Текст</p>
     );
   }
   ```

## Практическое задание 🎯

Давай создадим компонент "О себе":

1. **Измени содержимое App.jsx**:

```jsx
import './App.css';

function App() {
  const myName = "Мария"; // твоё имя
  const myAge = 25; // твой возраст
  const myHobbies = ["программирование", "чтение", "готовка"];

  return (
    <>
      <div style={{ textAlign: 'center', padding: '2rem' }}>
        <h1>Привет, меня зовут {myName}!</h1>
        <p>Мне {myAge} лет</p>
        <h2>Мои увлечения:</h2>
        <ul style={{ listStyle: 'none', padding: 0 }}>
          {myHobbies.map((hobby, index) => (
            <li key={index} style={{ margin: '0.5rem 0' }}>
              ✨ {hobby}
            </li>
          ))}
        </ul>
        <p>
          Я изучаю React с Vite и это супер круто! 🎉
        </p>
      </div>
    </>
  );
}

export default App;
```

2. **Замени данные на свои** — имя, возраст, увлечения
3. **Сохрани и посмотри результат** в браузере

:::tip[Что нового ты увидела?]
- **Фигурные скобки `{}`** позволяют вставлять JavaScript в JSX
- **Переменные** можно использовать прямо в разметке
- **Массивы** можно перебирать с помощью `map()`
- Каждый элемент списка должен иметь уникальный `key`
:::

## Остановка сервера разработки ⏹️

Когда захочешь остановить сервер:

1. Перейди в терминал, где запущен `npm run dev`
2. Нажми `Ctrl + C` (да, именно Ctrl, не Cmd!)
3. Подтверди остановку, если спросит

Чтобы запустить снова — `npm run dev` в папке проекта.
