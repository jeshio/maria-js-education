# 1.3 Компоненты, props и state 🧩

Привет! В прошлом уроке мы создали первое React приложение и познакомились с JSX. Сегодня мы изучим самые важные концепции React: **компоненты**, **props** и **state**. Это основа всего!

## Что такое компоненты? 🎭

:::tip[Компоненты - это кирпичики]
**Компонент** — это переиспользуемый кусочек интерфейса. Представь, что ты строишь дом из LEGO: каждый блочок — это компонент, а весь дом — это твоё приложение.
:::

Например, кнопка, карточка товара, форма входа — всё это компоненты. Один раз написал — можешь использовать везде!

### Создание своего первого компонента

Давай создадим компонент приветствия. В папке `src` создай новый файл `Greeting.jsx`:

```jsx
// src/Greeting.jsx
function Greeting() {
  return (
    <div style={{ 
      padding: '1rem', 
      border: '2px solid #61dafb', 
      borderRadius: '8px',
      margin: '1rem 0' 
    }}>
      <h2>Привет из компонента! 👋</h2>
      <p>Я — переиспользуемый компонент Greeting</p>
    </div>
  );
}

export default Greeting;
```

Теперь используем его в `App.jsx`:

```jsx
// src/App.jsx
import Greeting from './Greeting';
import './App.css';

function App() {
  return (
    <>
      <h1>Моё React приложение</h1>
      <Greeting />
      <Greeting />
      <Greeting />
    </>
  );
}

export default App;
```

🎉 **Вуаля!** Ты увидишь три одинаковых блока приветствия. Один компонент — много использований!

:::tip[Именование компонентов]
Компоненты **всегда** называй с большой буквы: `Greeting`, `UserCard`, `ShoppingCart`. Это важное правило React!
:::

## Props — передача данных в компоненты 📨

:::tip[Props = properties]
**Props** (сокращение от properties) — это способ передать данные в компонент. Как аргументы в функции, только для компонентов!
:::

### Компонент с props

Давай сделаем наш `Greeting` более гибким:

```jsx
// src/Greeting.jsx
function Greeting(props) {
  return (
    <div style={{ 
      padding: '1rem', 
      border: '2px solid #61dafb', 
      borderRadius: '8px',
      margin: '1rem 0' 
    }}>
      <h2>Привет, {props.name}! 👋</h2>
      <p>Тебе {props.age} лет</p>
      <p>{props.message}</p>
    </div>
  );
}

export default Greeting;
```

Теперь используем его с разными данными:

```jsx
// src/App.jsx
import Greeting from './Greeting';
import './App.css';

function App() {
  return (
    <>
      <h1>Семейные приветствия</h1>
      <Greeting 
        name="Мария" 
        age={25} 
        message="Ты изучаешь React!" 
      />
      <Greeting 
        name="Гоша" 
        age={30} 
        message="Ты помогаешь с программированием!" 
      />
      <Greeting 
        name="Того" 
        age={3} 
        message="Ты самый лучший пёс!" 
      />
    </>
  );
}

export default App;
```

:::tip[Деструктуризация props]
Можно писать красивее, "распаковывая" props:

```jsx
function Greeting({ name, age, message }) { // тут было `function Greeting(props) {`
  return (
    <div style={{ 
      padding: '1rem', 
      border: '2px solid #61dafb', 
      borderRadius: '8px',
      margin: '1rem 0' 
    }}>
      <h2>Привет, {name}! 👋</h2>
      <p>Тебе {age} лет</p>
      <p>{message}</p>
    </div>
  );
}
```

Это то же самое, но короче!
:::

### Типы данных в props

В props можно передавать что угодно:

```jsx
// Строки
<Greeting name="Мария" />

// Числа (в фигурных скобках!)
<Greeting age={25} />

// Булевые значения
<Greeting isStudent={true} />

// Массивы
<Greeting hobbies={["чтение", "готовка", "программирование"]} />

// Объекты
<Greeting user={{ name: "Мария", city: "Москва" }} />

// Функции
<Greeting onClick={() => alert("Привет!")} />
```

## State — состояние компонента 🔄

:::tip[State = изменяемые данные]
**State** — это данные, которые могут изменяться внутри компонента. Когда state меняется, компонент автоматически перерисовывается!
:::

### Наш первый state

Помнишь кнопку-счётчик из Vite? Давай создадим свою! Создай файл `Counter.jsx`:

```jsx
// src/Counter.jsx
import { useState } from 'react';

function Counter() {
  // useState возвращает массив: [значение, функция для изменения]
  const [count, setCount] = useState(0);
  // так используется деструктуризация, хотя тебе было бы
  // привычнее использовать такой формат (что тоже самое, но в целых 3 строки):
  // const counterState = useState(0);
  // const count = counterState[0];
  // const setCount = counterState[1];

  const handleIncrement = () => {
    setCount(count + 1);
  };

  const handleDecrement = () => {
    setCount(count - 1);
  };

  const handleReset = () => {
    setCount(0);
  };

  return (
    <div style={{ 
      padding: '2rem', 
      border: '2px solid #ff6b6b', 
      borderRadius: '8px',
      textAlign: 'center',
      margin: '1rem 0'
    }}>
      <h2>Счётчик: {count}</h2>
      <div>
        <button 
          onClick={handleDecrement}
          style={{ margin: '0 0.5rem', padding: '0.5rem 1rem' }}
        >
          ➖ Уменьшить
        </button>
        <button 
          onClick={handleReset}
          style={{ margin: '0 0.5rem', padding: '0.5rem 1rem' }}
        >
          🔄 Сброс
        </button>
        <button 
          onClick={handleIncrement}
          style={{ margin: '0 0.5rem', padding: '0.5rem 1rem' }}
        >
          ➕ Увеличить
        </button>
      </div>
      {count === 0 && <p>Счётчик обнулён!</p>}
      {count > 10 && <p>Ого, больше 10! 🎉</p>}
      {count < 0 && <p>Отрицательное число! 😅</p>}
    </div>
  );
}

export default Counter;
```

Добавь его в `App.jsx`:

```jsx
// src/App.jsx
import Greeting from './Greeting';
import Counter from './Counter';
import './App.css';

function App() {
  return (
    <>
      <h1>Моё React приложение</h1>
      <Counter />
      <Counter />
      {/* Каждый счётчик независим! */}
    </>
  );
}

export default App;
```

:::success[Магия state!]
Попробуй нажимать кнопки — каждый счётчик работает независимо! React автоматически обновляет только ту часть страницы, которая изменилась.
:::

### Правила работы с state

1. **Всегда используй функцию изменения когда меняешь state**:
   ```jsx
   // Правильно
   setCount(count + 1);
   
   // Неправильно - со state так делать нельзя!
   count = count + 1;
   ```

2. **State асинхронный**:
   ```jsx
   const handleClick = () => {
     setCount(count + 1);
     console.log(count); // покажет старое значение! Ещё до увеличения на 1
   };
   ```

3. **Для обновления на основе предыдущего значения используй функцию**:
   ```jsx
   // Безопасно для быстрых кликов
   setCount(prevCount => prevCount + 1);
   ```

## Объединяем props и state 🤝

Давай создадим компонент, который использует и props, и state. Сделаем "Лайкер":

```jsx
// src/LikeButton.jsx
import { useState } from 'react';

function LikeButton({ initialLikes = 0, itemName = "это" }) {
  const [likes, setLikes] = useState(initialLikes);
  const [isLiked, setIsLiked] = useState(false);

  const handleLike = () => {
    if (isLiked) {
      setLikes(likes - 1);
      setIsLiked(false);
    } else {
      setLikes(likes + 1);
      setIsLiked(true);
    }
  };

  return (
    <div style={{ 
      padding: '1rem', 
      border: '2px solid #e91e63', 
      borderRadius: '8px',
      margin: '1rem 0',
      textAlign: 'center'
    }}>
      <h3>Нравится {itemName}?</h3>
      <button 
        onClick={handleLike}
        style={{ 
          fontSize: '1.5rem',
          padding: '0.5rem 1rem',
          backgroundColor: isLiked ? '#e91e63' : '#f0f0f0',
          color: isLiked ? 'white' : 'black',
          border: 'none',
          borderRadius: '4px',
          cursor: 'pointer'
        }}
      >
        {isLiked ? '❤️' : '🤍'} {likes}
      </button>
      <p>
        {isLiked ? 'Ты лайкнула!' : 'Нажми на сердечко'}
      </p>
    </div>
  );
}

export default LikeButton;
```

Используем в `App.jsx`:

```jsx
// src/App.jsx
import LikeButton from './LikeButton';
import './App.css';

function App() {
  return (
    <>
      <h1>Семейные лайки</h1>
      <LikeButton 
        initialLikes={5} 
        itemName="программирование" 
      />
      <LikeButton 
        initialLikes={1} 
        itemName="готовка" 
      />
      <LikeButton 
        initialLikes={15} 
        itemName="Того" 
      />
    </>
  );
}

export default App;
```

:::tip[Значения по умолчанию]
Обрати внимание на `initialLikes = 0` в параметрах — это значения по умолчанию! Если props не передан, используется значение по умолчанию.
:::

## Практическое задание 🎯

Давай создадим простой "Переключатель темы" — компонент, который меняет цвет фона!

1. Создай файл `ThemeSwitcher.jsx`:

```jsx
// src/ThemeSwitcher.jsx
import { useState } from 'react';

function ThemeSwitcher() {
  const [isDark, setIsDark] = useState(false);

  const toggleTheme = () => {
    setIsDark(!isDark);
  };

  return (
    <div style={{ 
      padding: '2rem', 
      backgroundColor: isDark ? '#333' : '#fff',
      color: isDark ? '#fff' : '#333',
      border: '2px solid #ccc',
      borderRadius: '8px',
      margin: '1rem 0',
      textAlign: 'center'
    }}>
      <h2>Переключатель темы 🌓</h2>
      <p>
        Сейчас активна {isDark ? 'тёмная' : 'светлая'} тема
      </p>
      <button 
        onClick={toggleTheme}
        style={{ 
          padding: '0.75rem 1.5rem',
          fontSize: '1rem',
          backgroundColor: isDark ? '#fff' : '#333',
          color: isDark ? '#333' : '#fff',
          border: 'none',
          borderRadius: '4px',
          cursor: 'pointer'
        }}
      >
        {isDark ? '☀️ Светлая тема' : '🌙 Тёмная тема'}
      </button>
      <p style={{ marginTop: '1rem', fontSize: '0.9rem' }}>
        {isDark ? 'Тёмная тема лучше для глаз вечером' : 'Светлая тема лучше днём'}
      </p>
    </div>
  );
}

export default ThemeSwitcher;
```

2. Добавь в `App.jsx`:

```jsx
// src/App.jsx
import Greeting from './Greeting';
import Counter from './Counter';
import LikeButton from './LikeButton';
import ThemeSwitcher from './ThemeSwitcher';
import './App.css';

function App() {
  return (
    <>
      <h1>Мария изучает React! 🚀</h1>
      <Greeting name="Мария" age={25} message="Ты изучаешь React!" />
      <Counter />
      <LikeButton initialLikes={10} itemName="программирование" />
      <ThemeSwitcher />
    </>
  );
}

export default App;
```

3. Модифицируй наши компоненты:
- В ThemeSwitcher добавь счётчик переключений (покажи, сколько раз пользователь переключал тему)
- Добавь к компоненту Counter кнопку "Удвоить" и сделай так, чтобы при нажатии на неё счётчик удваивался
- Сделай LikeButton цветным: пусть кнопка меняет цвет в зависимости от количества лайков (например, зелёная при 0-1 лайков, жёлтая при 6-10, красная при 11+)

### Что нового ты узнала?

:::tip[Новые концепции]
- **Булевый state** — `true/false` для переключателей
- **Условное отображение** — показывать разное содержимое в зависимости от state
- **Условные стили** — менять CSS в зависимости от состояния
- **Логическое НЕ `!`** — для переключения булевых значений
- **Тернарный оператор `? :`** — короткая запись условий
:::
