# 1.1 Знакомство с React и терминалом 🚀

Добро пожаловать в мир современной веб-разработки! Сегодня мы познакомимся с **React** — одной из самых популярных библиотек для создания пользовательских интерфейсов, а также изучим терминал — незаменимый инструмент любого разработчика.

## Что такое React? 🤔

**React** — это JavaScript-библиотека для создания пользовательских интерфейсов, разработанная компанией Meta (Facebook). Представь, что HTML, CSS и JavaScript объединились в одну супер-технологию!

### Как выглядит обычный HTML vs React

<Tabs>
<TabItem value="html" label="Обычный HTML + JS">

```html
<!-- index.html -->
<div id="counter">
  <h2>Счётчик: <span id="count">0</span></h2>
  <button onclick="increment()">+1</button>
</div>

<script>
let count = 0;

function increment() {
  count++;
  document.getElementById('count').textContent = count;
}
</script>
```

</TabItem>
<TabItem value="react" label="React">

```jsx
// Counter.jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Счётчик: {count}</h2>
      <button onClick={() => setCount(count + 1)}>
        +1
      </button>
    </div>
  );
}
```

</TabItem>
</Tabs>

### Почему React такой крутой? ✨

1. **Компонентность** — всё разбивается на переиспользуемые кусочки
2. **Реактивность** — интерфейс автоматически обновляется при изменении данных
3. **JSX** — можешь писать HTML прямо в JavaScript
4. **Экосистема** — огромное сообщество и множество готовых решений

:::tip[Простыми словами]
Если HTML — это скелет сайта, CSS — его одежда, а JavaScript — мозги, то React — это волшебная палочка, которая делает всё это умным и живым! 🪄
:::

## Знакомство с терминалом на Mac 💻

Терминал — это текстовый интерфейс для управления компьютером. Звучит страшно? На самом деле это супер-мощный инструмент!

### Как открыть терминал

1. **Cmd + Пробел** → набери "Terminal" → Enter
2. Или найди в `Программы` → `Утилиты` → `Терминал`

### Твой первый терминал выглядит так:

```bash
Marias-MacBook:~ maria$
```

Это значит:
- `Marias-MacBook` — имя твоего Mac
- `~` — ты находишься в домашней папке
- `maria` — твоё имя пользователя
- `$` — готовность к вводу команды

## Основные команды терминала 🛠️

### Навигация по папкам

```bash
# Показать текущую папку
pwd

# Показать содержимое папки
ls

# Показать содержимое с подробностями
ls -la

# Перейти из текущей папки в папку с названием Desktop (Это рабочий стол)
cd Desktop

# Подняться на папку выше
cd ..
```

### Работа с файлами и папками

:::warning
Не забывай убедиться, что находишься в нужной папке при выполнении следующих команд.
:::

```bash
# Вернуться в домашнюю папку
cd ~

# Создать папку
mkdir my-project

# Создать файл
touch index.html

# Удалить файл
rm index.html

# Удалить папку со всеми файлами и папками внутри (будь осторожна!)
rm -rf my-project

# Скопировать файл
cp file1.txt file2.txt

# Переместить/переименовать файл
mv old-name.txt new-name.txt
```

### Полезные команды

```bash
# Очистить экран
clear

# Показать историю команд
history

# Остановить выполнение команды
Command + C

# Автодополнение команды/пути
Tab

# Показать содержимое файла
cat package.json
```

:::warning[Осторожно с rm!]
Команда `rm` удаляет файлы навсегда, в обход Корзины. Всегда проверяй что удаляешь! 🗑️
:::

## Примеры - зачем фронтендеру терминал? 🎯

:::info
Эти команды не нужно вводить, они только для примера.
:::

### 1. **Установка инструментов**
```bash
# Установить Node.js пакеты
npm install react

# Установить глобальные инструменты
npm install -g create-react-app
```

### 2. **Создание проектов**
```bash
# Создать новое React приложение
npx create-react-app my-app

# Создать проект с Vite (быстрее!)
npm create vite@latest my-app -- --template react
```

### 3. **Запуск разработки**
```bash
# Запустить сервер разработки
npm start

# Собрать проект для продакшена
npm run build
```

### 4. **Работа с Git**
```bash
# Инициализировать git репозиторий
git init

# Добавить файлы для коммита
git add .

# Сделать коммит
git commit -m "Мой первый коммит"
```

### 5. **Управление зависимостями**
```bash
# Посмотреть установленные пакеты
npm list

# Обновить пакеты
npm update

# Удалить пакет
npm uninstall package-name
```

## Практическое задание 📝

Давай попрактикуемся с терминалом:

1. **Открой терминал** и выполни команду `pwd` — где ты находишься?

2. **Создай структуру проекта:**
   ```bash
   # сначала перейди в папку, где ты хочешь создать проект, потом выполни следующие команды
   mkdir my-first-react-project
   cd my-first-react-project
   mkdir src
   mkdir public
   touch src/App.js
   touch public/index.html
   ls -la
   ```

3. **Навигация:**
   ```bash
   cd src
   pwd
   cd ..
   pwd
   cd ~
   pwd
   ```

4. **Посмотри содержимое:**
   ```bash
   cd my-first-react-project
   ls
   ls -la
   ```

:::success[Отлично!]
Ты только что создала структуру проекта через терминал! Это основа работы терминала. 🎉
:::
